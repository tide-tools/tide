ПЕРВЫЙ ЧАС

Один проход: поставил → дом → проект → доска → первая закрытая работа.
На каждом шаге написано, что ты увидишь.

Нужен Python ≥ 3.12; для последнего шага — Claude Code (сама механика tide работает и без него). Команды показаны, чтобы ты понял цикл руками — в живой работе их ходит агент, а ты говоришь словами.

Уже поставил? tide quickstart печатает этот маршрут прямо в терминале. English — quickstart.

1 · ПОСТАВИТЬ

git clone https://github.com/tide-tools/tide && cd tide
./install.sh

Увидишь ✓ tide <версия> и следующий жест. Если PATH не подхватился — скрипт печатает одну строку для профиля шелла, и это единственное, что тут можно «настраивать».

2 · ДОМ

Дом (control-home) — одна папка, из которой ты ведёшь все проекты:

mkdir ~/tide-home && cd ~/tide-home
tide init --git

Увидишь список созданного — канон, ростер, плагины, README, git, а также хуки и скиллы Claude, вставшие сами: агент, открытый в этом доме, с первого дня умеет передать нить. Свежий дом получает только кор, съёмные части — в tide plugins. В конце — следующий жест.

3 · СКАЗАТЬ ШЕЛЛУ, ГДЕ ДОМ

export TIDE_HOME=~/tide-home    # добавь в профиль шелла

Пропустишь — следующий шаг всё равно заведёт проект, но не впишет его в ростер, и на доске он не появится. Это не ошибка, просто одна пропущенная строка посреди успешного прогона: · roster no control-home — set $TIDE_HOME.

4 · ПРОЕКТ

Проект — любая папка с кодом, старая или новая:

mkdir -p ~/code/myapp && cd ~/code/myapp
tide adopt --goal "маленькое веб-приложение — пробую tide"

Увидишь шаги усыновления, потом — какой терминал будет открывать твои сессии и чем это поменять, потом следующий жест. Проект рождается говорящим: README и канон несут твою цель, а не шаблонную воду, и он уже в ростере дома.

5 · ДОСКА

tide board --open               # http://127.0.0.1:8765

Увидишь поток дома, поток myapp и строку HEALTH у каждого. Страница перечитывает .tide/ каждые 30 секунд — всё, что ты делаешь дальше, появляется там без перезапуска. Про телефон и службу — docs/board.ru.md.

6 · ПЕРВАЯ РАБОТА

Работа — карточка согласия: агент предлагает шаги, ты говоришь «да», агент чекает пункты только с пруфом, закрываешь ты. Вербы работают из коробки; съёмная часть добавляет скилл агенту и вкладку на доске:

tide plugins on work            # один раз на дом

cd ~/code/myapp
tide work add "приложение здоровается — проверить, что стартует"
tide work propose 01 "запустить и увидеть ответ"          # жест агента
tide work agree 01 --word "да"                            # твоё слово
tide work take 01 --by "первая сессия"
tide work check 01 1 --proof "запустил — отвечает"        # без пруфа не чекнется
tide work close 01 --word "принято"                       # done ставит только рука

Увидишь короткий ответ после каждого жеста — что произошло и что дальше — а на доске карточку, прошедшую open → taken → review → done. tide work show 01 печатает журнал: каждый жест строкой, с твоими словами внутри.

7 · СЕССИЯ

cd ~/tide-home
tide menu

Увидишь выбор проекта, потом нити, потом сессии внутри неё — в каждом списке первой строкой 0) + new. Откроется терминал, где Claude уже в контексте: своя роль, канон проекта, живая нить, ростер. Дальше ты говоришь словами («заведи работу…», «передай нить»), а вербы из шага 6 агент ходит сам.
