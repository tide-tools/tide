# Правила нити tide

Одно место правил работы в нити (SOC-181). Сид передачи, сид запуска `tide go`,
`prompts/orchestrator.md`, `prompts/worker.md` и `rules/subagents.md` ссылаются сюда,
а не копируют. Правится только этот файл; пороги `tide escalate` в коде
(`tide.escalate_rules`) сверяет с ним тест.

- работа: файлы — в workspace/ своей арки, итог — в output/; пульс по ходу — tide offload; передать дальше — /handoff
- итог сабагента — не длиннее ~600 токенов (~2000 знаков); подробности — файлом в workspace/ своей арки, в итоге — путь к файлу
- тесты: сабагент не ждёт прогон дольше ~4,5 мин в одном вызове — долгие (полный tide-ci) в фоне (Bash run_in_background), проверка по готовности
- почта: ao send между сессиями — только сигнал: 1–2 строки + «письмо NNN в почте нити»; текст — tide mail send <проект>/<нить>; несрочное — пингом пачкой до 25 мин, срочное — --urgent
- троттлинг: перед новым сабагентом или тяжёлым прогоном — tide throttle status; на паузе новые сабагенты не запускай, доведи шаг до коммита; потолок агентов достигнут — жди; окно ≥85% — только точечные тесты
- модели: рутина помощников — model: sonnet (поиск, чтение, Explore, прогоны, смоук, сводки); код и ревью — Opus; долгие прогоны в фоне, проверка кусками ≤4 мин
- отчёт: по готовности работы (итог задачи, In Review, конец цикла, хендофф) — tide report --done … --proof … --next … --waits … --soc SOC-N: сделано с пруфом · дальше · ждёт пользователя; уходит в TG-тему проекта и ленту «Отчёты» на доске
- опыт: наступил на граблю — сразу tide thread layer --exp "…", не ждать передачи
- не справляешься — tide escalate --what … --tried … --need …: 2 неудачные попытки одного шага, или стоп дольше 30 мин без прогресса (ждать ответа Гриши/менеджера — не застревание), или задача вне твоей роли/прав (отказ role-gate — отдай сабагенту, это не повод); письмо уйдёт main проекта, без квитанции 30 мин — менеджеру; закрыть — tide escalate --close NNN --word "чем"
